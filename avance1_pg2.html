  filter(!is.na(horas), !is.na(comprension))

  arrange(marca) |>
  group_by(correo, fecha) |>

df <- df |>
  mutate(
    sueno = cut(
      horas,
      breaks = c(-Inf, 5, 7, 9, Inf),

      ordered_result = TRUE
    )
  )

n <- nrow(df)

Parte 1: Probabilidad empírica

Código 
tabla_prob <- function(x) {
  t <- table(x)
  tibble(
    evento = names(t),
    n = as.integer(t),
    P = round(as.numeric(t) / sum(t), 4)
  )
}

Variable 1: Horas de sueño (cuantitativa continua, categorizada)

Rangos según las horas de sueño \(h\): Muy corto: \(h \leq 5\); Corto: \(5 < h \leq 7\); Adecuado: \(7 < h \leq 9\); Largo: \(h > 9\).

  1. Experimento aleatorio: seleccionar un registro al azar del estudio y observar las horas de sueño de la noche pasada.
  2. Espacio de resultados: Ω = {Muy corto, Corto, Adecuado, Largo}
  3. Eventos atómicos: cada evento consiste en seleccionar un registro al azar del estudio cuyas horas de sueño pertenezcan a la categoría indicada (por ejemplo, Muy corto: 5 h o menos). Son atómicos porque cada uno corresponde a un único resultado de Ω: no se pueden dividir en eventos más pequeños dentro de este espacio, son mutuamente excluyentes (un registro pertenece a una sola categoría) y juntos cubren todo Ω, por lo que sus probabilidades suman 1.
  4. Probabilidades:

3. Propiedades de la probabilidad

Diferencia simétrica: los registros que están en \(E_1\) o en \(E_2\), pero no en ambos (\(E_1 \triangle E_2\)). Su probabilidad es

\[P(E_1 \triangle E_2)=P(E_1)+P(E_2)-2P(E_1 \cap E_2)\]

Desigualdad triangular: como \(P(A \triangle B)\) mide qué tan distintos son dos eventos, cumple la desigualdad triangular \(P(A \triangle C) \leq P(A \triangle B)+P(B \triangle C)\). Tomando \(A=E_1\), \(B=\varnothing\) y \(C=E_2\) se obtiene

\[P(E_1 \triangle E_2) \leq P(E_1)+P(E_2)\]

4. Teorema de Bayes

P(E₂|E₁) = P(E₁|E₂)·P(E₂) / [ P(E₁|E₂)·P(E₂) + P(E₁|E₂ᶜ)·P(E₂ᶜ) ]

Código 
p_e1_dado_e2  <- p12 / p2
p_e1_dado_e2c <- mean(E1[!E2])
p2c <- 1 - p2

total <- p_e1_dado_e2 * p2 + p_e1_dado_e2c * p2c   # probabilidad total = P(E1)
bayes <- (p_e1_dado_e2 * p2) / total

5. Interpretación en el contexto del estudio

  • Independencia: P(E₁ ∩ E₂) = 0.18 y P(E₁)·P(E₂) = 0.192. Sin redondear, la diferencia P(E₁ ∩ E₂) − P(E₁)·P(E₂) es -0.0117, distinta de cero, por lo que los eventos no son independientes. La diferencia es pequeña: la relación entre dormir 7 horas o menos y el nivel de comprensión es débil en estos datos.
  • Probabilidad condicional: P(E₁|E₂) = 0.621. Entre los registros con comprensión alta o muy alta, el 62.1% corresponde a estudiantes que durmieron 7 horas o menos, algo menos que en el total de registros (66.2%).
  • Bayes: P(E₂|E₁) = 0.272. Dado que el estudiante durmió 7 horas o menos, la probabilidad de tener una comprensión alta o muy alta es de 27.2%, ligeramente menor que la probabilidad general de 29%.

En el contexto del estudio, quienes duermen 7 horas o menos reportan una comprensión alta o muy alta algo menos seguido que el resto de estudiantes. La diferencia es de pocos puntos porcentuales, por lo que no se puede concluir que el sueño por sí solo determine la comprensión. Se trata de una asociación leve observada en la sección. Otros factores, como el uso de IA o las horas de estudio, podrían influir en la comprensión, pero son solo hipótesis: no se evaluaron en este análisis.
