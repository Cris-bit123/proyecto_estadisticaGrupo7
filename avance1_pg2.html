Parte 1: Probabilidad empírica

Código 
tabla_prob <- function(x) {
  t <- table(x)
  tibble(
    evento = names(t),
    n = as.integer(t),
    P = round(as.numeric(t) / sum(t), 4)
  )
}

Variable 1: Horas de sueño (cuantitativa continua, categorizada)

Rangos según las horas de sueño \(h\): Muy corto: \(h \leq 5\); Corto: \(5 < h \leq 7\); Adecuado: \(7 < h \leq 9\); Largo: \(h > 9\).

  1. Experimento aleatorio: seleccionar un registro al azar del estudio y observar las horas de sueño de la noche pasada.
  2. Espacio de resultados: Ω = {Muy corto, Corto, Adecuado, Largo}
  3. Eventos atómicos: cada evento consiste en seleccionar un registro al azar del estudio cuyas horas de sueño pertenezcan a la categoría indicada (por ejemplo, Muy corto: 5 h o menos).
  4. Probabilidades:
Código

Parte 2: Probabilidad condicional

1. Eventos

  • E₁: seleccionar un registro al azar del estudio en el que el estudiante durmió 7 horas o menos.
  • E₂: seleccionar un registro al azar del estudio con nivel de comprensión alto o muy alto.
Código 
E1 <- df$horas <= 7
E2 <- df$comprension %in% c("Alto", "Muy alto")

p1  <- mean(E1)
p2  <- mean(E2)
p12 <- mean(E1 & E2)

P(E₁) = 0.6575, P(E₂) = 0.296, P(E₁ ∩ E₂) = 0.1859.

2. Prueba de independencia de eventos

indep3 <- round(p12, 3) == round(p1 * p2, 3)

Aproximando al tercer decimal, los eventos no son independientes; aproximando al segundo decimal, sí.

Con los valores sin redondear, P(E₁ ∩ E₂) = 0.185886 y P(E₁)·P(E₂) = 0.194643. La igualdad no se cumple, y la conclusión se basa en estos valores sin redondear.

4. Teorema de Bayes

P(E₂|E₁) = P(E₁|E₂)·P(E₂) / [ P(E₁|E₂)·P(E₂) + P(E₁|E₂ᶜ)·P(E₂ᶜ) ]

Código 
p_e1_dado_e2  <- p12 / p2
p_e1_dado_e2c <- mean(E1[!E2])
p2c <- 1 - p2

total <- p_e1_dado_e2 * p2 + p_e1_dado_e2c * p2c   # probabilidad total = P(E1)
bayes <- (p_e1_dado_e2 * p2) / total

c(`P(E1|E2)` = round(p_e1_dado_e2, 4),
  `P(E1|E2c)` = round(p_e1_dado_e2c, 4),
  `P(E2c)` = round(p2c, 4),
  `Prob. total` = round(total, 4),
  `P(E2|E1) Bayes` = round(bayes, 4))
      P(E1|E2)      P(E1|E2c)         P(E2c)    Prob. total P(E2|E1) Bayes

5. Interpretación en el contexto del estudio

  • Independencia: P(E₁ ∩ E₂) = 0.186 y P(E₁)·P(E₂) = 0.195. Sin redondear, la diferencia P(E₁ ∩ E₂) − P(E₁)·P(E₂) es -0.0088, distinta de cero, por lo que los eventos no son independientes. La diferencia es pequeña: la relación entre dormir 7 horas o menos y el nivel de comprensión es débil en estos datos.
  • Probabilidad condicional: P(E₁|E₂) = 0.628. Entre los registros con comprensión alta o muy alta, el 62.8% corresponde a estudiantes que durmieron 7 horas o menos, algo menos que en el total de registros (65.7%).
  • Bayes: P(E₂|E₁) = 0.283. Dado que el estudiante durmió 7 horas o menos, la probabilidad de tener una comprensión alta o muy alta es de 28.3%, ligeramente menor que la probabilidad general de 29.6%.

En el contexto del estudio, quienes duermen 7 horas o menos reportan una comprensión alta o muy alta algo menos seguido que el resto de estudiantes. La diferencia es de pocos puntos porcentuales, por lo que no se puede concluir que el sueño por sí solo determine la comprensión. Se trata de una asociación leve observada en la sección. Otros factores, como el uso de IA o las horas de estudio, podrían influir en la comprensión, pero son solo hipótesis: no se evaluaron en este análisis.
